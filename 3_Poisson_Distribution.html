Why does Poisson appear?

Start with a binomial story

Suppose there are many opportunities for an event to occur. Each opportunity has a small probability of success.

That is a binomial setting:

X∼Binomial(n,p)
Now make the event rare, but increase the number of opportunities

Let

n→large,  p→0,  np=λ

The expected number of events stays fixed at λ.

Then the binomial approaches Poisson

The Poisson distribution is the limiting form of the binomial distribution in this rare-event limit:

Binomial(n,p) → Poisson(λ)
Aha: Poisson is not an unrelated distribution. It emerges naturally when we count rare events occurring among many opportunities, while the expected number of events stays fixed.
